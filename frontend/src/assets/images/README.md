# Images Directory

This directory contains application images and graphics.

## Usage
- Place JPG, PNG, WebP, or other image files here
- Import images in components using relative paths
- Example: `import heroImage from '../assets/images/hero.jpg'`

## Naming Convention
- Use descriptive names: `hero-banner.jpg`, `user-avatar.png`
- Include size/resolution if relevant: `background-1920x1080.jpg`

## Optimization
- Compress images for web (use tools like ImageOptim, TinyPNG)
- Consider responsive images with different sizes
- Use WebP format for better compression when supported
- Lazy load images for better performance

## Categories
- `banners/` - Hero banners and headers
- `avatars/` - User profile pictures
- `thumbnails/` - Small preview images
- `backgrounds/` - Background images
