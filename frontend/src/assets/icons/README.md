# Icons Directory

This directory contains application icons.

## Usage
- Place SVG, PNG, or other icon files here
- Import icons in components using relative paths
- Example: `import logo from '../assets/icons/logo.svg'`

## Naming Convention
- Use kebab-case for file names: `user-icon.svg`, `menu-toggle.png`
- Include size in filename if multiple sizes: `logo-32x32.png`, `logo-64x64.png`

## Optimization
- Prefer SVG for scalability
- Optimize PNG/JPG files for web
- Use icon fonts or sprite sheets for multiple small icons
